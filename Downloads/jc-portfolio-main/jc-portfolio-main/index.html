Sistema para Agroferretería

Desarrollo de un sistema web integral bajo la arquitectura MVC para la administración y facturación de una ferretería agrícola, construido con Java (Servlets, JSP), JDBC y MariaDB en el backend, y Bootstrap 5 con JavaScript en el frontend. El software centraliza el control de inventarios, gestión de clientes y compras, e incorpora un Punto de Venta (POS) dinámico con cálculo automatizado de caja y vuelto. Destaca por su avanzado módulo de Cuentas por Cobrar para ventas a crédito —que permite registrar abonos y recalcular saldos dinámicamente con alertas de vencimiento en un dashboard inteligente—, y por su robusto sistema de seguridad que incluye control de acceso basado en roles (RBAC) y encriptación de contraseñas mediante BCrypt.

HTML CSS JavaScript MariaDB Jakarta EE Bootstrap Servlet JSP JDBC
